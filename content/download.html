MANUAL INSTALLATION

Installation

You can either build Chilen from source or use one of the official installation methods. If you wish to create a community build, contact me and I will happily list it here in a separate section!

warning

Only git builds are available at this time

Those builds are meant primarily for development and testing purposes. Daily driving Chilen as your music player is not recommended until a tagged release is published. It won't do anything destructive, but do expect issues!

Fedora

Enable the tpaau/chilen Copr repo:

{% include widgets/code-with-copy.html content="dnf copr enable tpaau/chilen" %}

Then install chilen-git on regular Fedora:

{% include widgets/code-with-copy.html content="dnf install chilen-git" %}

Or on Fedora Atomic:

{% include widgets/code-with-copy.html content="rpm-ostree install chilen-git" %}

Arch Linux

{% capture arch_git %}git clone https://github.com/tpaau/chilen-git-src-pkgbuild cd chilen-git-src-pkgbuild makepkg -si{% endcapture %} {% include widgets/code-with-copy.html content=arch_git %}

Or install the community build via an AUR helper:

{% include widgets/code-with-copy.html content="yay -Syu chilen-git-src" %}
